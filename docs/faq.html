Частые вопросы (FAQ)

Нужен ли домен для запуска VPN?

Нет. По умолчанию сразу работает VLESS + Reality по IP сервера. Домен нужен только если вы хотите включить Hysteria 2, NaiveProxy, xHTTP и Mieru.

Как открыть панель управления новичку?

По завершении установки веб-инсталлятор даёт готовые файлы open-panel-windows.bat и open-panel-mac-linux.sh. Достаточно запустить файл двойным кликом — он сам откроет SSH-туннель и страницу панели.

Не выпускается SSL-сертификат для домена

Перед добавлением домена нажмите в панели кнопку «Проверить DNS». Убедитесь, что A-записи основного домена и поддомена NaiveProxy указывают на внешний IP вашего сервера, а порт 80/tcp открыт у облачного провайдера.

Как проверить, всё ли работает на сервере?

Нажмите кнопку «🩺 Проверить здоровье сервера» в разделе системных служб — панель покажет состояние Xray, Caddy, Nginx, Hysteria 2, Mita, WARP, портов 80/443, диска и памяти.
